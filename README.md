# Mac-to-galaxy

Mac과 갤럭시를 USB로 연결해 파일을 탐색하고 미리 보거나 서로 복사하는 macOS 앱입니다.

Mac-to-galaxy는 독립적으로 개발한 비공식 앱이며, Apple 또는 삼성전자의 공식 제품이나 제휴 앱이 아닙니다.

**실기 검증 대상**은 갤럭시 Z 플립7의 One UI 9.0과 Apple Silicon Mac의 macOS 27.2.1입니다. 앱의 배포 대상은 macOS 14 이상입니다.

## 빌드 및 실행

Homebrew와 Swift 5.9 이상을 제공하는 Xcode 또는 Command Line Tools가 필요합니다. Command Line Tools가 없는 Mac에서는 먼저 `xcode-select --install`을 실행합니다.

```bash
brew install libmtp pkgconf
./scripts/build-app.sh
open dist/Mac-to-galaxy.app
```

빌드 스크립트는 이 Mac에서 실행할 `.app`을 `dist/`에 만들고 로컬 서명을 적용합니다. 실행 시 이 Mac의 Homebrew에 설치된 `libmtp`와 `libusb`를 사용합니다.

## GitHub에서 앱 업데이트

처음 한 번 터미널에서 GitHub CLI를 설치하고 GitHub 계정으로 로그인합니다.

```bash
brew install gh
gh auth login --hostname github.com --web
```

앱 사이드바의 **앱 업데이트**를 누르면 GitHub `main`의 커밋을 확인합니다. 새 커밋이 있으면 이 Mac에서 빌드하고 서명을 검증한 뒤 앱을 교체하고 다시 엽니다. 저장소의 `main`에 변경을 반영하면 다음 업데이트 확인부터 받을 수 있습니다. 앱은 `dist` 또는 사용자 계정이 쓸 수 있는 폴더에서 실행하세요.

## USB 파일 전송

1. 데이터 전송용 USB 케이블로 연결합니다. Mac에 액세서리 연결 승인 창이 나타나면 허용합니다.
2. 갤럭시 화면 잠금을 해제하고 USB 알림의 용도를 **파일 전송**으로 바꿉니다. 데이터 접근 승인 창이 표시되면 허용합니다.
3. 앱에서 저장소와 폴더를 두 번 클릭하거나 선택하고 **열기**를 누릅니다. 파일을 한 번 선택한 뒤 **스페이스바** 또는 **미리보기**로 훑어볼 수 있습니다. 파일을 복사하려면 **Mac에 저장**을 누릅니다.

사진, 동영상, 오디오, PDF, 일반 텍스트는 macOS Quick Look으로 미리 볼 수 있습니다. 파일은 Mac으로 복사할 수 있으며, 같은 이름의 로컬 파일이 있으면 다른 저장 경로를 선택해야 합니다. 전송 중 케이블 연결이 끊기거나 취소하면 복사가 완료되기 전의 임시 파일을 정리합니다.

파일명은 확장자까지 NFC로 표시하고 저장합니다. UTF-8, BOM이 있는 UTF-16·UTF-32, 한국어 Windows CP949로 작성한 텍스트와 CSV·TSV는 미리보기에서 한글을 합칩니다. DOCX의 본문, XLSX의 셀, PPTX의 슬라이드는 텍스트로 미리 볼 수 있습니다. 본문 처리는 임시 미리보기에 적용하며, USB 전송은 파일의 원본 바이트를 그대로 복사합니다.

Mac의 파일을 보내려면 앱에서 갤럭시의 대상 폴더를 열고 **Mac에서 보내기**를 누릅니다. Mac 파일 한 개를 선택하면 갤럭시에서 파일 크기를 확인한 후 최종 이름으로 표시합니다. 같은 이름의 파일이나 폴더가 있으면 전송을 중단합니다. 연결 해제로 임시 파일 정리를 확인할 수 없으면 앱에서 임시 파일 이름을 안내합니다.

저장소가 열리지 않으면 갤럭시에서 파일 전송이 선택되어 있는지 확인하고, Smart Switch 등 USB를 사용하는 다른 앱을 종료한 뒤 **파일 새로고침**을 누릅니다.

## 검증

```bash
swift test
```

`swift test`는 파일명 정규화, 사용할 수 없는 이름, 같은 이름의 항목 처리 등 공통 파일 로직을 검사합니다. macOS 앱은 위의 빌드 명령으로 확인합니다.
macOS에서 `./scripts/test-app-update.sh`를 실행하면 테스트용 GitHub 응답으로 최신 버전 판정, 실패 시 기존 앱 보존, 교체와 복구를 확인합니다.

### Z 플립7 실기 검증 결과

갤럭시 Z 플립7을 USB 파일 전송 모드로 연결해 Apple Silicon Mac에서 확인했습니다.

| 항목 | 확인한 결과 |
| --- | --- |
| 기기 인식 및 폴더 탐색 | 내부 저장소와 하위 폴더를 열고, 선택한 갤럭시 폴더가 **Mac에서 보내기** 창에 표시되는 것을 확인했습니다. |
| 갤럭시 → Mac | 한글 이름의 TXT·HWP·HWPX 파일을 저장했습니다. 파일명은 원본과 같은 NFC 형태였고, 원본과 저장본의 SHA-256이 일치했습니다. HWPX의 내부 본문 XML도 원본과 일치했습니다. |
| 스페이스바 미리보기 | 한글 TXT의 Quick Look 임시 사본이 원본과 바이트까지 일치했습니다. |
| Mac → 갤럭시 | 한글 이름의 TXT·HWPX를 보낸 뒤 갤럭시에서 다시 읽어 파일명과 파일 바이트가 원본과 일치하는 것을 확인했습니다. 내장 저장공간 최상위에는 0바이트 파일을 보내 크기도 확인했습니다. |
| 중복 차단 | 확장자의 대소문자만 다른 파일을 같은 폴더로 보냈을 때 전송이 중단됐고, 기존 파일의 바이트가 보존됐습니다. |
| 전송 취소 및 복구 | 96 MiB 파일을 보내는 도중 취소했습니다. 갤럭시에 완료 파일과 임시 파일이 남지 않았고, 연결이 복구된 뒤 다시 보내고 Mac으로 저장할 수 있었습니다. 실기에서 복구에는 수십 초가 걸렸습니다. |

양방향 전송 결과는 한글 파일명 저장 수정과 Mac에서 보내기 기능을 검증할 때 기록했습니다. [한글 파일명 저장 수정](https://github.com/ljwoo8942/Mac-to-galaxy/commit/a54304de61ba5201f13b1c24bfc97d5e4f89b0b9) · [Mac에서 보내기](https://github.com/ljwoo8942/Mac-to-galaxy/commit/cdc1c8cdb745a82fd4ff9794e70d306adea0f3d3)

파일 전송 전용 빌드에서는 USB 연결과 폴더 탐색, 보내기 창을 확인했습니다. [파일 전송 전용 빌드](https://github.com/ljwoo8942/Mac-to-galaxy/commit/a28ff6c1d6b82b88856d2d99dc514eca747472b1)

USB 허브를 거친 연결, 전송 중 케이블 분리, 한컴오피스에서의 본문 표시는 실기 검증 전입니다.

## 구성

- `MacToGalaxy`는 SwiftUI 화면, IOKit USB 기기 탐색, 앱 업데이트를 담당합니다.
- `MTPBridge`는 `libmtp`의 저장소 조회와 파일 읽기·쓰기를 Swift에 연결합니다.
- `GalaxyCore`에는 USB 기기·파일의 데이터 형식과 파일명 처리 로직이 있습니다.
