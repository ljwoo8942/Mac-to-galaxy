# Mac-to-galaxy

Mac을 갤럭시에 USB로 연결해 파일을 탐색하고 USB 테더링을 확인하는 macOS 앱입니다. 파일 목록과 테더링 상태를 한 창에서 볼 수 있습니다.

**첫 실기 검증 대상**은 갤럭시 Z 플립7의 One UI 9.0과 Apple Silicon Mac의 macOS Golden Gate 27.2.1입니다. 현재 이 조합의 앱 실행과 USB 동작은 실기 확인 전입니다. 앱의 배포 대상은 macOS 14 이상으로 설정되어 있습니다.

## 빌드 및 실행

Homebrew와 Swift 5.9 이상을 제공하는 Xcode 또는 Command Line Tools가 필요합니다. Command Line Tools가 없는 Mac에서는 먼저 `xcode-select --install`을 실행합니다.

```bash
brew install libmtp pkgconf
./scripts/build-app.sh
open dist/Mac-to-galaxy.app
```

빌드 스크립트는 이 Mac에서 실행할 `.app`을 `dist/`에 만들고 로컬 서명을 적용합니다. 실행 시 이 Mac의 Homebrew에 설치된 `libmtp`와 `libusb`를 사용합니다.

## GitHub에서 앱 업데이트

처음 한 번 터미널에서 GitHub CLI를 설치하고 비공개 저장소에 접근할 수 있는 계정으로 로그인합니다.

```bash
brew install gh
gh auth login --hostname github.com --web
```

앱 사이드바의 **앱 업데이트**를 누르면 GitHub `main`의 커밋을 확인합니다. 새 커밋이 있으면 이 Mac에서 빌드하고 서명을 검증한 뒤 앱을 교체하고 다시 엽니다. 저장소의 `main`에 변경을 반영하면 다음 업데이트 확인부터 받을 수 있습니다. 앱은 `dist` 또는 사용자 계정이 쓸 수 있는 폴더에서 실행하세요.

## 갤럭시 파일 보기

1. 데이터 전송용 USB 케이블로 연결합니다. Mac에 액세서리 연결 승인 창이 나타나면 허용합니다.
2. 갤럭시 화면 잠금을 해제하고 USB 알림의 용도를 **파일 전송**으로 바꿉니다. 데이터 접근 승인 창이 표시되면 허용합니다.
3. 앱에서 저장소와 폴더를 두 번 클릭하거나 선택하고 **열기**를 누릅니다. 파일을 한 번 선택한 뒤 **스페이스바** 또는 **미리보기**로 훑어볼 수 있습니다. 파일을 복사하려면 **Mac에 저장**을 누릅니다.

사진, 동영상, 오디오, PDF, 일반 텍스트는 macOS Quick Look으로 미리 볼 수 있습니다. 파일은 Mac으로 복사할 수 있으며, 같은 이름의 로컬 파일이 있으면 다른 저장 경로를 선택해야 합니다. 전송 중 케이블 연결이 끊기거나 취소하면 복사가 완료되기 전의 임시 파일을 정리합니다.

저장소가 열리지 않으면 갤럭시에서 파일 전송이 선택되어 있는지 확인하고, Smart Switch 등 USB를 사용하는 다른 앱을 종료한 뒤 **파일 새로고침**을 누릅니다.

## USB 테더링

1. 갤럭시의 모바일 데이터를 켭니다.
2. USB 연결을 유지한 상태에서 **설정 → 연결 → 모바일 핫스팟 및 테더링 → USB 테더링**을 켭니다.
3. 앱에서 **IP 할당됨**이 표시되면 **USB 인터넷 확인**을 누릅니다.

앱은 macOS가 갤럭시에 연결된 USB 네트워크 인터페이스를 생성하고 IP를 받은 경우 그 인터페이스에 고정된 HTTPS 요청을 보냅니다. 확인 주소는 `https://www.google.com/generate_204`이며 버튼을 눌렀을 때만 요청합니다. 성공은 해당 USB 경로에서 연결이 확인됐다는 뜻입니다. Mac의 기본 네트워크 경로 변경은 필요에 따라 macOS **네트워크 설정**에서 합니다.

**RNDIS 감지됨**과 함께 macOS 네트워크 인터페이스를 찾지 못했다는 메시지가 표시되면 Mac의 **네트워크 설정**에서 USB 네트워크 서비스가 생겼는지 확인합니다. 테더링은 macOS에서 인식한 인터페이스를 사용하며, 별도의 RNDIS 드라이버는 포함되어 있지 않습니다.

One UI의 USB 모드에 따라 테더링을 켤 때 파일 전송이 일시 중지될 수 있습니다. 갤럭시를 파일 전송 모드로 돌리면 앱이 저장소 연결을 다시 시도합니다.

## 검증

```bash
swift test
```

리눅스의 `swift test`는 USB 방식 감지, 네트워크 인터페이스와 기기의 연결 관계, 다중 기기 처리, 인터넷 응답 판정, 파일명 처리에 대한 공통 로직을 검사합니다. macOS 앱은 위의 빌드 명령으로 확인합니다.
macOS에서 `./scripts/test-app-update.sh`를 실행하면 테스트용 GitHub 응답으로 최신 버전 판정, 실패 시 기존 앱 보존, 교체와 복구를 확인합니다.

### Z 플립7 실기 체크리스트

| 항목 | 확인할 결과 |
| --- | --- |
| 파일 탐색 | 화면 잠금 해제와 접근 허용 후 내부 저장소와 하위 폴더가 열립니다. |
| 미리보기와 복사 | 사진과 동영상이 열리고, 저장한 파일의 크기와 내용이 원본과 일치합니다. |
| 테더링 | Mac의 Wi‑Fi를 끈 상태에서 갤럭시의 USB 인터페이스에 IP가 할당되고, **USB 인터넷 확인**이 성공합니다. |
| 모드 전환 | 파일 전송과 테더링을 동시에 사용할 수 있는지 기록합니다. 전환으로 파일 연결이 끊기면 파일 전송 모드 복귀 후 저장소가 다시 표시됩니다. |
| 연결 해제 | 케이블을 뽑으면 앱 상태가 초기화됩니다. 다시 연결하면 기기를 인식하고 중단된 복사의 임시 파일이 남지 않습니다. |

결과에는 Mac의 `sw_vers` 출력과 Z 플립7의 One UI 버전 및 빌드 번호를 기록합니다. 테더링에 실패한 경우 앱에 표시된 USB 방식과 시스템 네트워크 설정에서 해당 인터페이스를 찾을 수 있었는지도 함께 기록합니다.

## 구성

- `MacToGalaxy`는 SwiftUI 화면, IOKit USB 탐색, Network.framework 기반 인터넷 확인을 담당합니다.
- `MTPBridge`는 `libmtp`의 저장소 조회와 파일 읽기를 Swift에 연결합니다.
- `GalaxyCore`에는 기기·네트워크 상태 판단과 플랫폼 공통 로직이 있습니다.
